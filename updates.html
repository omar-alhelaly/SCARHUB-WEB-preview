Changelog

2026-11-24

v2.1 Accounts, community and credited tools

  • Login, account area, community chat and a hidden admin page, ready to switch on once the backend is connected.
  • Three new tools: SCARJWT, SCARPERM and SCARLIST.
  • Eighteen open-source tools by other people, each credited with its creator, license and original link.
2026-11-24

v2.0 The company site

  • New Home, About, Solutions, Docs, Updates, FAQ and Security pages.
  • Tools grouped into 7 classes with filter and search.
  • The SCAR logo always returns to Home.
2026-11-24

v2.0 Nine new tools

  • SCARBASE, SCARPASS, SCARHEADERS, SCARTIME, SCARCVSS, SCARMETA, SCARPORTS, SCARDIFF and SCARHASH.
  • Each one has its own public GitHub repository with tests, README and MIT license.
2026-11-24

v1.3 Arabic layout

  • Right to left layout for every page when Arabic is selected.
2026-11-24

v1.2 Themes and hover demos

  • Dark and light mode, remembered between visits.
  • Hover a card to see a half-card animated terminal demo of the tool's commands.
2026-11-24

v1.0 Launch

  • First release with 13 tools, a poster and a contact page, in English and Arabic.
