Documentation

Get from zero to a running tool in four steps, then use the quick reference.

Getting started

1. Get Python

Check that Python 3 is installed.

python3 --version

2. Get a tool

Subscribers get the tools from their account. Tool pages list what each one does.

3. Run it

Run the single file with Python. No install step.

python3 scarbase.py --help

4. Run the tests

Public tools ship with unit tests.

python3 -m unittest

Quick reference

SCAROSINT

Keyless reconnaissance for Kali Linux. DNS, web, TLS, archives and registration data for a domain you own, no API keys.

SCAROSINT your-owned-domain.comPrivate repository Recon & Network

SCARLAN

Local network inventory and exposure reporter. Lists hosts, open ports and services on a private range you own, and shows what changed since the last run.

scarlan demoPrivate repository Recon & Network

SCARPORTS

Offline reference for common network ports with a one-line security note for each. Look up by number or service name.

Recon & Network

SCARCUSTODY

Evidence hashing with a tamper-evident chain-of-custody log. Each entry holds the hash of the previous one, so edits break the chain.

scarcustody init --name CASE-042 --actor "Omar"Private repository Forensics & DFIR

SCARLOG

Log analyzer for forensics and defense. Reads SSH/auth and web access logs, builds one timeline and reports observations such as brute force and probe paths.

scarlog --helpPrivate repository Forensics & DFIR

SCARIOC

Indicator of Compromise extractor. Pulls IPs, domains, URLs, emails, hashes and CVEs from logs and reports. Understands defanged input. Offline, stdlib only.

scarioc incident.logPrivate repository Forensics & DFIR

SCARTIME

Timestamp converter and log timeline merger. Understands Unix seconds, ms and us, Windows FILETIME, ISO 8601, syslog and web access log formats.

Forensics & DFIR

SCARMETA

File identifier. Detects the real type from magic bytes, flags extension mismatches and high-entropy (packed or encrypted) content.

Forensics & DFIR

SCARHASH

Hash files and verify sha256sum-style checksum lists. Reports OK, FAILED and MISSING for each file.

Forensics & DFIR

SCARBASE

File integrity baseline and drift checker. Hash a folder, save a baseline, later see exactly what was added, removed or changed.

Defense & Hardening

SCARDIFF

Config diff that ignores comments, blank lines and whitespace. Shows only the lines that really changed.

Defense & Hardening

SCARHEADERS

HTTP security header checker. Grades the headers of a site you own and gives the one-line fix for each missing header.

Defense & Hardening

SCARENGAGE

Penetration test engagement tracker. Client, authorization reference, validated scope, findings, evidence hashes and client-ready reports. No scanning features.

scarengage demoPrivate repository Pentest & Reporting

SCARREPORT

Turns SCAROSINT JSON into a clean HTML and Markdown report with an executive summary, ordered findings and a simple fix for each.

scarreport report.jsonPrivate repository Pentest & Reporting

SCARCVSS

CVSS v3.1 base score calculator. Give it a vector, get the score and the severity. Checked against known vectors.

Pentest & Reporting

SCARCIPHER

Classical and modern encryption toolkit for learning. Caesar, Playfair, Hill, DES, 3DES and AES written from scratch and checked against NIST vectors.

Crypto & Decoding

SCARDECODE

Encoder, decoder and analysis tool. base64, hex, URL, ROT13 and more, auto-detects chained encodings, decodes JWTs, identifies hash types.

scardecode magic "VTJGc2RHVmtYMStCMFJBSm9BPT0="Private repository Crypto & Decoding

SCARPASS

Offline password auditor and generator. Estimates entropy, flags common passwords and patterns, makes random passwords and passphrases. Nothing is stored or sent.

Crypto & Decoding

SCARJWT

JSON Web Token decoder and auditor. Flags alg none, missing expiry, risky headers and sensitive claims, and checks HMAC signatures. Offline.

Crypto & Decoding

SCARDRONE

Defensive drone-security toolkit for authorized labs: perimeter scan, software audit, MAVLink anomaly analysis, parameter audit and wireless posture.

Drone & Mobile

SCARGRAB

Android app: paste or share a link, choose video or MP3/M4A and the quality, save to Downloads/SCARGRAB. Kotlin, Compose and yt-dlp. For personal use.

Drone & Mobile

SCARPERM

Android permission explainer. Rates permissions from names or a decoded AndroidManifest.xml and says why each one matters.

Drone & Mobile

SCARHUB

One launcher for the whole SCAR toolkit: menu, install check, help and examples per tool, guided workflows, install and update from git.

Platform & Productivity

SCARNOTE

Terminal notes and cheatsheet manager. Local, searchable, tags, optional passphrase encryption, Markdown import and export.

scarnote seedPrivate repository Platform & Productivity

SCARLIST

Markdown checklists for engagements. Web, network and DFIR templates, tick items off and see progress. Exit code 1 while work remains.
