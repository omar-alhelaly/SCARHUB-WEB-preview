Glossary

Glossary

Plain-language definitions of 98 security terms, in English and Arabic. Search, or pick a topic.

Core ideas

CIA triad

ثالوث CIA

The three goals of information security: Confidentiality, Integrity and Availability. Most security decisions protect at least one of them.

Confidentiality

السرية

Only the people who are allowed to see data can see it. Encryption and access control protect it.

Integrity

التكامل

Data is not changed without permission, and any change can be detected. Hashes and digital signatures help prove it.

Availability

الإتاحة

Systems and data work when people need them. Backups, redundancy and protection against denial of service keep them available.

Authentication

التوثيق

Proving who you are, for example with a password, a code or a key. It answers the question: who is this?

Authorization

التصريح

Deciding what an authenticated user may do. It answers: what is this person allowed to access?

Non-repudiation

عدم الإنكار

The ability to prove that someone did an action, so they cannot honestly deny it later. Signed logs and digital signatures support it.

Multi-factor authentication (MFA)

التحقق متعدد العوامل

Logging in with two or more different kinds of proof: something you know (password), something you have (phone or key) and something you are (fingerprint).

Least privilege

أقل صلاحية

Give each user or program only the access it needs, and nothing more. This limits the damage when an account is stolen.

Defense in depth

الدفاع متعدد الطبقات

Using several layers of protection, so one failure does not expose everything. For example a firewall, patching, MFA and monitoring together.

Zero trust

انعدام الثقة

A model where nothing is trusted by default, even inside the network. Every request is checked for identity and permission.

Threat

التهديد

Anything that could cause harm to a system or data, such as an attacker, malware or a natural disaster.

Vulnerability

الثغرة

A weakness that a threat can use. It can be a software bug, a bad setting or a human habit.

Risk

المخاطرة

The chance that a threat uses a vulnerability, combined with how bad the result would be. Risk = likelihood and impact.

Attack surface

سطح الهجوم

All the places where an attacker could try to get in: open ports, web pages, accounts, apps and people. A smaller surface is safer.

Patch

التحديث الأمني

A software update that fixes a bug or a vulnerability. Installing patches quickly is one of the cheapest defenses.

Hardening

التحصين

Making a system safer by removing what is not needed, closing ports and changing weak default settings.

Baseline

خط الأساس

A saved known-good state to compare against later. Any difference from it deserves a look.

Drift

الانحراف عن الأساس

When a system slowly changes away from its baseline, for example a new open port or a changed setting nobody recorded.

Scope

النطاق

The exact list of systems, accounts and actions you are allowed to test or investigate. Anything outside it is off limits.

Attacks and threats

Phishing

التصيّد

A fake message that pretends to be a trusted sender to steal passwords or make you open something harmful.

Social engineering

الهندسة الاجتماعية

Tricking people instead of breaking systems. The attacker uses trust, urgency or fear to get information or access.

Malware

البرمجيات الخبيثة

Software made to harm or spy: viruses, worms, trojans, spyware and ransomware.

Ransomware

برمجيات الفدية

Malware that locks or encrypts files and asks for payment to unlock them. Offline backups are the best answer.

Brute force

الهجوم بالتخمين

Trying many passwords or keys until one works. Long passphrases, rate limits and lockouts slow it down.

Credential stuffing

حشو بيانات الدخول

Trying leaked username and password pairs from one site on other sites, hoping people reused them.

Denial of service (DoS)

حجب الخدمة

Overloading a service so real users cannot use it. When many machines do it together, it is called DDoS.

Man-in-the-middle (MITM)

الرجل في المنتصف

An attacker secretly sits between two parties and reads or changes their traffic. HTTPS and certificate checks defend against it.

Zero-day

ثغرة اليوم صفر

A vulnerability that is already being used or is unknown to the vendor, so no patch exists yet.

Privilege escalation

رفع الصلاحيات

Gaining more access than you were given, for example going from a normal user to an administrator.

Lateral movement

الحركة الجانبية

Moving from one compromised machine to others inside the same network to reach valuable targets.

Backdoor

الباب الخلفي

A hidden way to get back into a system without the normal login.

Botnet

شبكة البوتات

A group of infected devices controlled by one attacker, often used for DDoS or spam.

Web security

XSS (cross-site scripting)

البرمجة عبر المواقع XSS

An attacker gets a script to run inside a page other users view. Output encoding and a strong CSP prevent it.

SQL injection

حقن SQL

Sending input that changes a database query. Parameterized queries stop it.

CSRF

تزوير الطلبات CSRF

Making a logged-in user's browser send a request they did not mean to. Anti-CSRF tokens and SameSite cookies help.

CSP

سياسة أمان المحتوى CSP

A header that tells the browser which scripts, styles and images a page may load. It limits the damage of XSS.

HSTS

HSTS

A header that tells browsers to use only HTTPS for a site, so they never try plain HTTP.

Clickjacking

الاختطاف بالنقر

Hiding a real page under a fake one so the user clicks something they cannot see. Frame restrictions prevent it.

Cookie flags

خصائص الكوكي

Settings that protect a cookie: HttpOnly hides it from scripts, Secure sends it only over HTTPS, SameSite limits cross-site use.

Session

الجلسة

The period after login during which the server remembers you, usually with a session cookie or token.

JWT

JWT

A signed token that carries claims such as who you are. Anyone can read it, so it must never hold secrets, and the signature must always be checked.

WAF

جدار حماية الويب WAF

A filter in front of a web app that blocks known attack patterns. It helps, but it does not replace fixing the code.

TLS / HTTPS

تشفير الويب (TLS وHTTPS)

Encryption for web traffic. TLS is the protocol, and HTTPS is HTTP running over TLS.

Input validation

فحص المدخلات

Checking that data from users has the expected shape before using it. It is the first defense against many injection bugs.

Networking

IP address

عنوان IP

A number that identifies a device on a network. IPv4 has 32 bits and IPv6 has 128 bits.

Port

البورت

A numbered door on a machine that a service listens on, for example 443 for HTTPS and 22 for SSH.

DNS

نظام أسماء النطاقات DNS

The system that turns names like example.test into IP addresses.

Firewall

الجدار الناري

A filter that allows or blocks traffic by rules such as address, port and direction.

VPN

الشبكة الخاصة الافتراضية

An encrypted tunnel between your device and another network. It protects traffic on untrusted networks.

Subnet

الشبكة الفرعية

A smaller part of a network. A /24 subnet has 256 addresses, of which 254 can be used by hosts.

Packet

الحزمة

A small chunk of data sent over a network, with a header that says where it comes from and where it goes.

Port scan

فحص البورتات

Checking which ports on a machine answer, to learn which services run there. Only do it on systems you are allowed to test.

IDS / IPS

نظام كشف / منع التسلل

An intrusion detection system raises an alert on suspicious traffic. An intrusion prevention system also blocks it.

Proxy

الوسيط (Proxy)

A server that sits between a client and the internet and passes requests along. It can filter, cache or hide the client address.

Cryptography

Hash

الهاش

A fixed-size fingerprint of data. The same input always gives the same output, and you cannot go back from the hash to the data.

Salt

الملح (Salt)

Random data added to a password before hashing, so two equal passwords do not give the same hash.

Encryption

التشفير

Scrambling data with a key so only someone with the right key can read it.

Symmetric encryption

التشفير المتماثل

One shared key both encrypts and decrypts. It is fast. AES is a common example.

Asymmetric encryption

التشفير غير المتماثل

A pair of keys: a public key to encrypt or verify, and a private key to decrypt or sign. RSA is a common example.

Digital signature

التوقيع الرقمي

A value made with a private key that proves who created data and that it was not changed.

Certificate

الشهادة الرقمية

A signed file that links a public key to an identity, such as a website. Browsers use it to check they reached the right server.

Entropy

الإنتروبي

A measure of how unpredictable something is. A password with more entropy is harder to guess.

Passphrase

عبارة المرور

A long password made of several words. It is easier to remember and harder to guess than a short complex password.

Encoding

الترميز

Changing the format of data so it can be stored or sent, such as Base64. It is not secret: anyone can decode it.

Key management

إدارة المفاتيح

Creating, storing, rotating and destroying keys safely. Strong encryption fails if the keys are handled badly.

Forensics and SOC

DFIR

التحقيق الرقمي والاستجابة DFIR

Digital forensics and incident response: finding out what happened on a system and handling the incident.

Chain of custody

سلسلة الحيازة

A record of who held a piece of evidence and when. It shows the evidence was not changed.

Order of volatility

ترتيب التطاير

Collect the data that disappears fastest first: memory, then network state, then disk, then logs and backups.

Disk image

نسخة الديسك

A bit-for-bit copy of a drive. Investigators work on the copy and keep the original untouched.

Magic bytes

البايتات السحرية

The first bytes of a file that show its real type, for example %PDF at the start of a PDF.

FILETIME

FILETIME

A Windows timestamp: the number of 100-nanosecond steps since 1 January 1601 (UTC).

IoC (indicator of compromise)

مؤشر الاختراق

A trace that suggests a system was attacked, such as a file hash, an IP address or a domain.

Defanged

منزوع الخطورة

An IoC written so it cannot be clicked or run by mistake, for example hxxp://example[.]test.

SOC

مركز العمليات الأمنية SOC

Security operations center: the team that watches alerts and logs and responds to incidents.

SIEM

نظام SIEM

A platform that collects logs from many sources, correlates them and raises alerts.

Log

السجل (Log)

A time-ordered record of events on a system, such as logins, errors and requests.

Triage

الفرز الأولي

Quickly sorting alerts or evidence by urgency, so the most serious ones are handled first.

False positive

إنذار كاذب

An alert that fires although nothing bad happened. Too many of them make people ignore alerts.

Incident response

الاستجابة للحوادث

The steps taken when an attack is found: prepare, detect, contain, remove the cause, recover and learn.

Timeline

الخط الزمني

Events from many sources put in time order, to understand what happened and in which sequence.

Pentest and risk

Penetration test

اختبار الاختراق

An authorized, planned attempt to find and prove weaknesses in a system, followed by a report with fixes.

Reconnaissance

الاستطلاع

The first phase: collecting information about a target before testing it.

OSINT

الاستخبارات من المصادر المفتوحة

Open-source intelligence: information found in public sources such as websites, records and social posts.

Enumeration

الحصر

Listing details of a target, such as users, services and versions, after you find it.

Rules of engagement

قواعد الاشتباك

The written agreement that sets what may be tested, when, how and who to call if something breaks.

Red team / Blue team

الفريق الأحمر / الأزرق

The red team plays the attacker. The blue team defends and responds. Working together, they improve defenses.

Exploit

الاستغلال

Code or a method that uses a vulnerability to make a system do something it should not.

Payload

الحمولة

The part of an attack that does the actual action after the vulnerability is used.

Proof of concept (PoC)

إثبات المفهوم

A small safe demonstration that a weakness is real, without causing harm.

CVE

CVE

A public ID for a known vulnerability, such as CVE-2099-0001. It lets everyone talk about the same issue.

CVSS

CVSS

A 0 to 10 score for how severe a vulnerability is. It helps decide what to fix first.

Responsible disclosure

الإفصاح المسؤول

Reporting a vulnerability privately to the owner and giving time to fix it before telling the public.

AI security

LLM

نموذج لغوي كبير LLM

A large language model: an AI trained on lots of text that writes and answers in natural language.

Prompt injection

حقن الأوامر

Text that tries to override a model's instructions, often hidden in content the model reads. Treat model input as untrusted.

Hallucination

الهلوسة

When a model states something false with confidence. Always check important answers against a reliable source.

Training data

بيانات التدريب

The data used to teach a model. Its quality and privacy decide a lot about the model's behavior.

Data leakage

تسريب البيانات

Private information escaping through a model or tool, for example when someone pastes secrets into a public chatbot.
