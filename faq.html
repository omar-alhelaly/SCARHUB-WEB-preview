FAQ

Quick answers about the toolkit.

What is SCAR?

SCAR is a toolkit of command-line security tools written by Zenoth, for labs, CTFs, SOC work and authorized engagements.

Are the tools free?

The public tools are MIT licensed. Some older tools are private repositories and are listed without links.

Do I need API keys or accounts?

No. The tools run offline or against targets you choose, and need no keys.

What do I need to run them?

Python 3 on Linux, macOS or Windows. Kali has it already. No pip installs for the public tools.

Can I scan any site or network?

No. Use the tools only on systems you own or have written permission to test. Network-facing tools ask you to confirm this.

How do I report a bug or a security issue?

Open an issue in the tool's repository, or use the Contact page for anything sensitive.

Is there a video demo?

Cards show an animated terminal demo on hover. Recorded videos are on the roadmap.

Does the site work in Arabic?

Yes. Use the language button in the navigation. The layout flips to right to left and your choice is remembered.
