Incident Stories

Famous real cyber incidents that shaped the world, told as short educational case studies with links to the published sources.

These pages are short educational summaries written from the public sources linked on each card. All credit belongs to the original authors and publishers. We do not copy their work and we include no exploit code or step by step attack instructions. Read the original source for the full details.

PHP2Shell: remote code execution through out-of-memory handling (2026)

Vulnerability

A critical flaw in how PHP reacts when a request runs out of memory. Under the right conditions an unauthenticated visitor could run code on the server. Fixed on 21 October 2026.

CVE-2026-109618 | CVSS v4.0 9.2 Critical (PHP Group)

PHP Foundation: today's PHP security releaseRead the storyRead the source

PHP2Shell: remote code execution through stale request state (2026)

Vulnerability

The second critical PHP flaw fixed on 21 October 2026. A later request could reuse memory that belonged to an earlier one, which could be turned into code execution.

CVE-2026-109619 | CVSS v4.0 9.2 Critical (PHP Group)

PHP GitHub advisory GHSA-6wmf-4rv5-p3rpRead the storyRead the source

phpAfterShell: PHP session files that turn into code execution (2026)

Vulnerability

A critical flaw in PHP's default session storage, disclosed on 19 November 2026. A half written session file could be read back as objects chosen by an attacker.

CVE-2026-126714 | CVSS v4.0 9.2 Critical (PHP Group)

PHP GitHub advisory GHSA-fm2m-fjf5-v3cpRead the storyRead the source

PHP-FPM request smuggling (2026)

Vulnerability

A critical flaw where leftover request bytes could be read by PHP-FPM as a new, forged request. It only applies when the web server reuses its connections to PHP-FPM.

CVE-2026-129289 | CVSS v4.0 9.2 Critical (PHP Group)

PHP GitHub advisory GHSA-qc49-hpvq-g2w6Read the storyRead the source

PHP-CGI argument injection on Windows, CVE-2024-4577 (2024)

Vulnerability

A critical flaw in PHP-CGI on Windows. A character conversion step let a visitor slip options into the PHP command line. Published 9 June 2024.

CVE-2024-4577 | CVSS v3.1 9.8 Critical (PHP Group)

PHP GitHub advisory GHSA-3qgc-jrrr-25jvRead the storyRead the source

Colonial Pipeline ransomware (2021)

Critical infrastructure

In May 2021 a ransomware attack linked to the DarkSide group hit Colonial Pipeline, a major US fuel pipeline operator. CISA and the FBI published an advisory with background and recommended defenses.

Lesson: Ransomware can disrupt physical services, so protect the business side as well as the operational side.

CISA and FBI advisory AA21-131ARead the storyRead the source

Log4Shell and Apache Log4j (2021)

Vulnerability

In December 2021 a serious flaw in Apache Log4j, a very common Java logging library, put countless applications at risk. CISA published guidance for organizations on finding affected software and updating it.

Lesson: Know which libraries your software depends on, so you can react fast when one is found vulnerable.

CISA guidanceRead the storyRead the source

SolarWinds supply chain compromise (2020)

Supply chain

Attackers compromised SolarWinds Orion, a widely used network management product, and used it to reach government agencies, critical infrastructure and private companies. CISA's alert describes the compromise of a software component as one of the initial access routes.

Lesson: Trusted vendor software is part of your attack surface, so watch it and limit its access.

CISA alert AA20-352ARead the storyRead the source

Capital One data theft (2019)

Data breach

In July 2019 a former software engineer was charged over the theft of data from servers holding Capital One data. The US Department of Justice said the intrusion went through a misconfigured web application firewall.

US Department of Justice press releaseRead the storyRead the source

WannaCry and the NHS (2017)

Ransomware

In May 2017 the WannaCry ransomware spread worldwide. The UK National Audit Office found that at least 81 of 236 NHS trusts in England were affected, plus 603 primary care and other NHS organizations, including 595 GP practices.

Lesson: Keep systems patched, keep tested backups, and separate critical networks.

UK National Audit Office, 2017Read the storyRead the source

NotPetya (2017)

Destructive malware

A destructive attack that looked like ransomware and spread widely in 2017, hitting many companies worldwide. The US Government publicly attributed the NotPetya malware to the Russian military. WIRED's long read tells how it unfolded and what it cost.

Lesson: Plan for attacks that destroy data, not only ones that ask for money.

Andy Greenberg, WIRED, 2018 and CISA alert TA17-181ARead the storyRead the source

Equifax breach (2017)

Data breach

Hackers stole the personal data of nearly 150 million people from Equifax, a US consumer credit reporting company. The US Government Accountability Office reviewed how Equifax and federal agencies responded.

Lesson: Companies that hold personal data must be ready to detect a breach and respond fast.

US Government Accountability Office, GAO-18-559, 2018Read the storyRead the source

OPM data breach (2015)

Government

Attackers broke into systems of the US Office of Personnel Management, the agency that handles federal employee records, and sensitive personal data of current and former staff was stolen. A 2016 US House Oversight Committee report reviewed what went wrong and criticized the agency's security management.

Lesson: The most sensitive records need strong access control and up-to-date systems.

US House Committee on Oversight and Government Reform, 2016Read the storyRead the source

Ukraine power grid attack (2015)

Industrial

On 23 December 2015, power companies in Ukraine had unscheduled outages after a cyber attack. It is one of the first confirmed cyber attacks to cause a power outage.

CISA: Cyber-Attack Against Ukrainian Critical InfrastructureRead the storyRead the source

Heartbleed (2014)

Vulnerability

A bug in OpenSSL's heartbeat feature let anyone read pieces of a server's memory, including keys and passwords.

CVE-2014-0160

The Heartbleed BugRead the storyRead the source

Stuxnet (2010)

Industrial

Malware found in 2010 that targeted industrial control systems at Iran's Natanz nuclear enrichment site. It is widely described as the first known digital weapon to cause physical damage. No government has officially confirmed who built it, although press reports have pointed to the United States and Israel.

Lesson: Air-gapped networks are not automatically safe, and industrial systems need patching and monitoring.

Kim Zetter, WIRED, 2014Read the storyRead the source
