Recent threats

New vulnerabilities explained in simple words: what it is, why it matters and how to protect yourself.

Original explanations written from the public sources linked under each post. We include no exploit code and no attack steps. Facts were taken from the CISA catalog data and the vendor advisories linked in its entries. Read the original source for full details.

Mitel MiCollab: five flaws in the web conferencing part

2026-11-25

CISA added five Mitel MiCollab flaws to its Known Exploited Vulnerabilities catalog on 25 November 2026. All five are in the Audio, Web and Video Conferencing (AWV) component and CISA describes them as reachable without logging in.

What it is

MiCollab is a business communication product (calls, meetings, messaging). The five entries are an OS command injection (CVE-2026-133323), an XML injection (CVE-2026-133303), weak authentication (CVE-2026-133311), unrestricted upload of a dangerous file type (CVE-2026-133275) and a "not failing securely" flaw (CVE-2026-133324) that can let someone skip authentication checks.

Why it matters

An attacker who needs no password and can reach the conferencing part of the server may run commands or upload files. A phone and meeting system often sits close to the internal network, so one weak server can become a way in. CISA lists a required-action date of 28 November 2026 for most of these entries (9 December 2026 for the weak authentication one) for US federal agencies. Use of these flaws by ransomware groups is listed as unknown.

How to protect yourself

  • Follow the vendor advisory and apply the listed mitigations or updates.
  • Check whether the conferencing part is reachable from the internet. If it does not need to be, close it.
  • Review the server for unexpected files and accounts, because the catalog marks these as already used in attacks.
Sources Mitel advisory MISA-2026-0012

Danfoss AK-SM 800A: three flaws in a store monitoring system

2026-11-25

On the same day CISA added three Danfoss AK-SM 800A Series flaws. The product monitors refrigeration and similar equipment in shops.

What it is

The three entries are improper input validation that could let a remote attacker run commands (CVE-2023-25915), a path traversal that can read system files through the XML interface (CVE-2023-25914) and improper authentication that can generate a web report showing internal IP addresses, usernames and store names (CVE-2025-41450).

Why it matters

Two of the CVE numbers are from 2023, so this is a good reminder that old flaws stay dangerous. Devices like this are installed once and often never updated. The leaked internal addresses and usernames also help an attacker plan the next step.

How to protect yourself

  • Check the vendor security advisories for your model and update.
  • Keep devices like this off the open internet. Reach them only from the inside or through a VPN.
  • Keep an inventory of such devices, so none is forgotten.
Sources Danfoss advisory DSA-2023-08-01 Danfoss advisory DSA-2025-03-01

What is the Known Exploited Vulnerabilities catalog?

2026-11-27

The list used for the two posts above, and how to use it as a beginner.

The idea

CISA keeps a public list of flaws that are known to be used in real attacks. The version we read, 2026.11.25 (released 25 November 2026), holds 1805 entries. Thousands of flaws are published every year, but only a small part is used in attacks, so this list tells defenders where to start.

How to read an entry

Each entry has the CVE number, the vendor and product, a short description, the date it was added, a required action and a due date, and a field that says if ransomware groups are known to use it. As a student, pick one entry and answer three questions: what is the weakness type, what does it let an attacker do, and what is the fix. That is how our rooms teach it too.

How to protect yourself

  • Use the catalog to decide what to patch first.
  • Read the vendor advisory, not just the headline.
