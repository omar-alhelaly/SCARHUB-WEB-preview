Build one timeline from several logs

During an incident you often have an auth log and a web log. Merge them so events line up in order.

1

Convert odd timestamps first

Windows and Unix timestamps look different. Convert a sample to be sure of the timezone.

scartime convert 133444736000000000
2

Merge the logs

Each line is tagged with the file it came from.

scartime merge auth.log access.log
3

Pull out indicators

Extract IPs, domains and hashes from the merged output.

scartime merge auth.log access.log | scarioc -f json
Authorized use only. Follow these steps only on systems and data you own or are authorized to test.
