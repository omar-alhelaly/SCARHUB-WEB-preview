Glossary

Glossary

Short definitions for the terms used on this site.

Baseline

A saved known-good state to compare against later.

Brute force

Trying many passwords until one works.

CSP

Content Security Policy, a header that limits where a page can load scripts and content from.

CVSS

Common Vulnerability Scoring System, a 0 to 10 score for how severe a vulnerability is.

Chain of custody

A record of who handled evidence and when, so it stays trustworthy.

Clickjacking

Tricking a user into clicking something hidden under a visible page.

DFIR

Digital forensics and incident response.

Defanged

A URL or IP written so it is not clickable, like hxxp://example[.]com.

Drift

Unplanned change from a baseline.

Entropy

A measure of randomness. High entropy in a file can mean encryption or packing.

FILETIME

The Windows timestamp: 100 ns ticks since 1601-01-01 UTC.

HSTS

A header that tells browsers to use HTTPS only.

Hash

A fixed-size fingerprint of data. Any change in the data changes the hash.

IoC

Indicator of compromise: an IP, domain, hash or file that points to an attack.

JWT

JSON Web Token, a signed token often used for sessions.

Magic bytes

The first bytes of a file that show its real format.

OSINT

Open-source intelligence: information from public sources.

Passphrase

A password made of several random words, long but easy to remember.

SOC

Security operations center, the team that watches and responds to threats.

Scope

The systems and actions a test is authorized to cover.
